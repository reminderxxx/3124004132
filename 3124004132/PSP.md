# PSP 记录

## 开发前思考

我准备使用 Python 3 完成本次作业。选择 Python 的原因是中文文本处理、单元测试和性能分析工具比较方便，同时不需要额外发布可执行文件。

这次作业不仅要得到一个重复率，还要求记录完整的软件开发过程。我希望把输入输出、相似度计算、异常处理和测试拆开完成，避免最后一次性写完后难以定位问题。

下面的预计时间在正式编码前填写。完成项目以后，我会补充实际耗时，并比较预估和实际开发过程之间的差距。
